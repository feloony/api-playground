# API Playground ◈

A focused, browser-based REST API client for sending requests, inspecting responses, and debugging endpoints without a heavy setup.

## ✨ Features

- GET, POST, PUT, PATCH, DELETE and HEAD
- Query parameter builder
- Custom request headers
- JSON request body editor
- Status, response time and response size
- Pretty JSON response viewer
- Raw response viewer
- Response headers viewer
- One-click copy
- Quick example endpoints
- Responsive UI

## 🌐 CORS

Requests use the browser Fetch API. The target API must permit cross-origin browser requests. APIs that block CORS require a server-side proxy.

## 🔒 Privacy

No account or built-in request database is required. Requests are initiated by your browser. Never paste production secrets into untrusted environments.

## 🚀 Run

```bash
git clone https://github.com/feloony/api-playground.git
cd api-playground
```

Open `index.html` or use any static web server.

## 🛠️ Stack

HTML · CSS · Vanilla JavaScript · Fetch API
